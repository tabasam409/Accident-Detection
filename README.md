# Accident Detection using Deep Learning

## Description
A deep learning project that detects accidents in images using Convolutional Neural Networks (CNN). The model is trained on a dataset of accident and non-accident images to classify whether an accident has occurred.

## Technologies
- Python
- TensorFlow / Keras
- OpenCV
- NumPy
- Matplotlib
- Jupyter Notebook

## Trained Model
The trained model (`Model.h5`, ~316MB) is not included in this repository due to its large size. You can retrain the model by running the notebook with the appropriate dataset.

## How to Run
1. Clone the repository:
   ```bash
   git clone https://github.com/tabasam409/Accident-Detection.git
   cd Accident-Detection
   ```
2. Install dependencies:
   ```bash
   pip install tensorflow keras opencv-python numpy matplotlib
   ```
3. Open and run the Jupyter Notebook:
   ```bash
   jupyter notebook "Accident detection.ipynb"
   ```

## Dataset
The model was trained using a dataset organized into `train/`, `test/`, and `val/` directories. The dataset is not included in this repository.
